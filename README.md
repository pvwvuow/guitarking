# 🎸 گیتارکینگ (GuitarKing)

**آهنگ بده، آکوردِ تک‌تک بخش‌هاش رو بگیر!**

گیتارکینگ یک وب‌اپلیکیشن فارسی است که فایل MP3 (یا WAV / M4A / OGG / FLAC) آهنگ را می‌گیرد، آهنگ را به بخش‌های سازگار تقسیم می‌کند و **آکورد هر بخش را با زمان دقیق** نمایش می‌دهد — به‌همراه کلید آهنگ، تمپو و پخش همگام که آکوردِ «همین حالا» را هنگام شنیدن آهنگ هایلایت می‌کند.

## ✨ امکانات

| امکان | توضیح |
|---|---|
| 🎼 تشخیص آکورد | ۶۱ الگو: ماژور، مینور، دومینانت هفتم (7)، ماژور هفتم (maj7)، مینور هفتم (m7) و «بدون آکورد» |
| 🧩 بخش‌بندی آهنگ | تقسیم خودکار آهنگ به بخش‌های A / B / C بر اساس شباهت هارمونیک (تکرار بخش‌ها حرف یکسان می‌گیرند) |
| 🔑 کلید و تمپو | تشخیص گام (ماژور/مینور) با پروفایل‌های Krumhansl و محاسبه BPM |
| ▶️ پخش همگام | آکورد در لحظه‌ی پخش هایلایت می‌شود؛ کلیک روی هر آکورد = پرش به همان لحظه |
| 📊 خلاصه آماری | پرکاربردترین آکوردها بر اساس مدت پخش |
| 📄 خروجی متنی | کپی یا دانلود «برگه‌ی آکورد» به‌صورت TXT |
| 📱 ریسپانسیو | رابط فارسی راست‌به‌چپ با فونت وزیرمتن، مناسب موبایل و دسکتاپ |

## 🧠 موتور تشخیص چطور کار می‌کند؟

پایپ‌لاین پردازش سیگنال (سمت سرور، Python + librosa):

1. **جداسازی هارمونیک/پرکاسیو** (HPSS) — جزء هارمونیک برای هارمونی، جزء پرکاسیو برای ریتم
2. **کروماگرام CQT** + کرومای باس (فرکانس‌های زیر ۲۸۰ هرتز برای تشخیص نت پایه)
3. **شبکه‌ی یکنواخت همگام با ضرب** — دوران ضرب از beat tracking استخراج و روی کل آهنگ گسترش می‌یابد (مشکل شروع‌های بی‌ضرب اینترو حل می‌شود)
4. **تطبیق الگو + Viterbi** — بونوس انتقال به همان آکورد، نرمال‌سازی توانی برای احتمال‌های قابل مقایسه
5. **تشخیص کلید** — همبستگی کرومای میانگین با پروفایل‌های Krumhansl–Kessler
6. **بخش‌بندی ساختاری** — خوشه‌بندی سلسله‌مراتبی روی کرومای همگام‌شده + حداقل طول بخش + ادغام بخش‌های یکسان

## 🚀 راه‌اندازی

پیش‌نیازها: **Node.js 18+** (یا Bun)، **Python 3.9+**، **ffmpeg**

```bash
# 1) نصب وابستگی‌های Node
npm install        # یا: bun install

# 2) نصب وابستگی‌های Python
pip install -r python/requirements.txt

# 3) اجرا
npm run dev        # یا: bun run dev
```

سپس `http://localhost:3000` را باز کنید.

### متغیر محیطی اختیاری

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `GK_PYTHON` | `python3` | مسیر مفسر پایتونی که librosa دارد |

### استقرار

موتور پردازش به Python + librosa نیاز دارد؛ برای استقرار، یک سرور کوچک (VPS، Railway، Render و…) مناسب است. روی Vercel باید `GK_PYTHON` را به محیطی با librosa اشاره دهید یا موتور را به‌صورت سرویس جدا اجرا کنید. حداقل منابع پیشنهادی: ۱GB RAM.

## 🔍 نکته درباره‌ی دقت

تشخیص آکورد به‌صورت خودکار است و در آهنگ‌های پیچیده (مدولاسیون، آرتیکولاسیون‌های خاص، میکس‌های شلوغ) ممکن است خطا داشته باشد. بهتر است برگه‌ی خروجی را نقطه‌ی شروع تمرین بدانید، نه نسخه‌ی نهایی.
